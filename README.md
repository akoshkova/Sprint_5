# Автоматизированные тесты для Stellar Burgers

## Описание проекта
Автоматизированный набор тестов для проверки функционала веб-приложения Stellar Burgers. Проект включает тесты для проверки регистрации, авторизации, работы с личным кабинетом и конструктором бургеров.

## Структура проекта
```
stellar_burgers_tests/
├── README.md
├── .gitignore
├── page_objects/
│ └── locators.py
├── fixtures/
│ └── conftest.py
└── tests/
 ├── test_registration.py
 ├── test_login.py
 ├── test_profile.py
 ├── test_logout.py
 └── test_constructor.py
```

## Используемые технологии
* **Python** - основной язык программирования
* **Selenium WebDriver** - для автоматизации браузера
* **PyTest** - фреймворк для тестирования
* **ChromeDriver** - веб-драйвер для Google Chrome

## Функционал, покрытый тестами
* **Регистрация**:
  * Успешная регистрация
  * Валидация некорректных данных
  * Проверка ошибок ввода

* **Авторизация**:
  * Вход через главную страницу
  * Вход через личный кабинет
  * Вход через форму регистрации
  * Вход через восстановление пароля

* **Личный кабинет**:
  * Доступ к профилю
  * Переход в конструктор
  * Выход из аккаунта

* **Конструктор**:
  * Доступ к разделам (Булки, Соусы, Начинки)
  * Проверка работы без авторизации

## Запуск тестов
Для запуска тестов необходимо:
1. Установить Python
2. Установить зависимости: `pip install -r requirements.txt`
3. Запустить тесты: `pytest`
